测试用例管理
请先填写上方题目信息并点击"保存题目"，保存成功后即可上传测试用例。
测试用例文件格式说明
文件本质
  • 输入文件 = 选手 C++ 程序从 stdin 读到的全部字节
  • 输出文件 = 期望选手程序向 stdout 写出的全部字节
  • 推荐后缀：.in / .out（也支持 .txt，后端不限制扩展名）
  • 单文件 ≤ 10 MB，每题 ≤ 20 个用例
对比规则
  • 两端的尾部空白（空格 / Tab / 换行）会被忽略
  • 逐行比较（每行各自去尾部空白后比对）
  • "示例测试点"勾选仅做标记，不影响判题（所有用例都会跑）
判定结果
AC PE WA
  • AC 完全相同
  • PE 行内容一致但行数不同（格式错误）
  • WA 行内容不一致
